# cb21 — User Stories

Oct 15, 2026 · @Ramy Yasser

Terms (Clip, History, Capture, Recopy, Pause, and so on) are defined in `CONTEXT.md`.

## Epic

As a Mac user, I want a free, native clipboard history manager (cb21, short for clipboard 21) so I can re-use anything I've copied without re-copying it.

## Stories

CB-1 and CB-6 are additions to the original feature list: the other stories depend on capture, and Pause protects sensitive copies.

### CB-1: Capture clipboard history

As a user, I want everything I copy saved automatically, so nothing is lost when I copy something new.

- Each copy is stored as one Clip holding all its Representations: text, rich text, images, files and links.
- A Duplicate (a copy equal to the Clip at the top of History) is stored once. Copying A, B, A stores A twice, with the newer A on top.
- cb21's own Recopy writes are never captured again.
- Copies marked Concealed (`org.nspasteboard.ConcealedType`) or Transient (`org.nspasteboard.TransientType`) are Skipped copies. AutoGenerated copies are captured.
- A Clip larger than the storage Limit is not captured; the menu shows a one-time notice.
- History survives app restart and reboot.

### CB-2: Menu bar quick access

As a user, I want a menu bar icon that lists recent copies, so I can paste an old item in two clicks.

- Clicking the icon shows the 10 most recently used Clips, newest first.
- Previews: first line of text truncated to about 60 characters; a thumbnail for images; the file name for files; the URL for links; rich text shows its plain text.
- Clicking a Clip Recopies it. It moves to the top of History and is not captured again.
- The menu shows "Open history…", the Pause item (CB-6), "Clear all" and "Settings…".
- An optional global shortcut opens this menu from any app (see CB-3).
- On first launch, if pasteboard access is denied, the menu shows a short message linking to the System Settings pane.
- If the database can't be opened, the old file is moved aside under a timestamped name, History starts empty, and the menu shows a one-time notice.

### CB-3: Global shortcut

As a user, I want to bind my own shortcut to open the history, so I don't need the mouse.

- Settings has a shortcut recorder.
- The shortcut toggles the History window from any app.
- A second optional shortcut opens the menu bar list itself, and a third pauses or resumes capture (CB-6). All three are unbound by default and may not equal each other.
- Shortcuts without a modifier key (Cmd, Ctrl or Opt) are rejected, and so are known system shortcuts. Settings states that conflicts with other apps can't be detected.
- The default is unbound, and the user can reset it to unbound.

### CB-4: Delete history

As a user, I want to delete one, several, or all items, so I can remove sensitive or useless entries.

- The History window lists the full History.
- Single delete: per-Clip action (button or Delete key).
- Each row also has a Copy button: it puts the Clip on the pasteboard, makes it the most recent, and closes the window so the user can paste.
- A dot marks the most recently used Clip.
- Multi-select: Shift/Cmd-click, then delete.
- Clear all asks for confirmation.
- Deletion is permanent. Database rows are removed with SQLite `secure_delete` on, and image files are deleted immediately.
- The Clear all text in Settings says that History is stored unencrypted on disk.

### CB-5: Configure history size

As a user, I want to set how much history is kept, so cb21 uses only the memory and disk I allow.

- Two Limits: maximum number of Clips, and maximum storage size. Storage counts all stored bytes of every Representation, including image files.
- When either Limit is hit, the least recently used Clips are evicted first.
- Lowering a Limit trims existing History immediately, after a warning.
- Defaults are 100 Clips and 100 MB, and the settings persist.

### CB-6: Pause capture

As a user, I want to pause capture, so I can copy sensitive data that cb21 would otherwise keep.

- The menu has a Pause item with "Pause for 5 minutes", "Pause for 15 minutes" and "Pause until resumed".
- While paused, copies are Skipped copies, and the menu bar icon shows a distinct state.
- Pause ends on its own when its timer runs out, and always ends when cb21 restarts.
- Settings has an optional Pause shortcut, unbound by default, with the same conflict rules as CB-3.
- Recopy and deletion work normally while paused.

## Settings

A single pane with three sections:
- Shortcuts: History window, menu bar list (CB-3), Pause (CB-6).
- History: the two Limits (CB-5) and the Clear all text.
- General: launch at login, off by default.

## Definition of done

- Native macOS app (Swift/SwiftUI, with AppKit for the menu bar and pasteboard), macOS 14 (Sonoma) or later.
- Launches at login (optional toggle, off by default).
- No network access, no telemetry.
- Free. Distributed outside the App Store, ad-hoc signed, not notarized and not sandboxed (see `docs/adr/0002-direct-distribution-not-sandboxed.md`).

## Excluded from v1

| Excluded | Reason |
| --- | --- |
| Cloud/iCloud sync | Adds privacy risk and a backend, which conflicts with "free" |
| Search and pinning | Useful, but not in the feature list; easy to add as v1.1 |
| Paste as plain text | Recopy writes all Representations in v1; a plain-text option is a v1.1 candidate |
| Snippets/text expansion | Different product category |
| Per-app ignore list | Beyond the concealed-type check and Pause, this is extra scope |
| Encryption at rest | Worth considering later; adds Keychain complexity |

## Decisions

- Storage: SQLite, with image data as files on disk. See `docs/adr/0001-sqlite-with-image-files-on-disk.md`. This settles the earlier open decision.
- The database is checked at startup: orphaned image files from an interrupted delete are removed.
